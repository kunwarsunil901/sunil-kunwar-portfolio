# Sunil Kunwar — IT E-Portfolio

A responsive, dark-themed personal portfolio built with HTML5, CSS3 and vanilla JavaScript. It is ready to publish with GitHub Pages.

## Files

- `index.html` — portfolio content and page structure
- `assets/style.css` — responsive dark-theme styling
- `assets/script.js` — mobile navigation, project detail dialogs, and current-year footer

## Preview locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension, or run `python -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish using GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a new **public** repository named `sunil-kunwar-portfolio` (or another name you prefer).
3. Upload `index.html`, the `assets` folder, and this README to the repository's root. Do not upload only the ZIP file.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings. It will usually look like `https://YOUR-USERNAME.github.io/sunil-kunwar-portfolio/`.
